# System Sale Management
The Sales & Invoice Management System is a desktop application developed using Java, SWT, Hibernate Annotations, and MySQL. It allows users to manage products, users, and sales invoices through a simple interface while securely storing data in a database.

## 🚀 Features

- User Login Authentication
- User Management (Add, Update, Delete)
- Product/Item Management
- Create Sales Invoices
- Add Multiple Items to an Invoice
- Automatic Total Price Calculation
- Database Integration using Hibernate Annotations
- User-Friendly SWT Desktop Interface



### Main Menu
- Manage Users
- Manage Items
- Manage Invoices
- Exit Application

### User Management
- Add new users
- Update user information
- Delete users

### Item Management
- Add products
- Edit products
- Delete products
- View all products

### Invoice Management
- Create new invoices
- Select multiple items
- Calculate total automatically
- Save invoice to the database
